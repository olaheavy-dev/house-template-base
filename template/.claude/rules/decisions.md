# Decision records

- One record per hard-to-reverse decision, numbered `NNNN-short-title.md`, using the template in `0001-record-decisions.md`: context, decision, consequences, alternatives considered, and sources.
- Accepted records are not rewritten. To change one, write a new record that supersedes it and mark the old one `Superseded by NNNN`.
- Easily reversible choices get one line in the register in `docs/decisions/README.md`, not a record.
- Every factual claim in a record links its source (official documentation for the pinned version, a measurement, or an issue).
